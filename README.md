# Dynamic Table Generator

- This is a very simple JavaScript project that helps to create custom HTML tables dynamically based on user input.
- You can enter any number for rows and columns. When you click the button, JavaScript runs a loop and creates a beautiful grid structure on the screen instantly.

# Features
- Creates dynamic table layouts using document createElement methods.
- Uses nested loops to calculate and handle rows and columns safely.
- Input validation to check if fields are empty.

# Technology Used
- HTML5 for building the input text elements.
- JavaScript for executing loop controls and appending DOM nodes.
